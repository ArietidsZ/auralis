# Auralis v0.1.0-preview.1

**Developer Preview.** Prerelease tag `v0.1.0-preview.1`. Repository: [ArietidsZ/auralis](https://github.com/ArietidsZ/auralis).

Offline dialect speech translation on Android and iOS: ASR → MT → TTS, with optional voice cloning from a local reference. No network inference.

This tag is source and build tooling. It is not a store listing, not a hardware certification, and not a physical-device performance result. Final unit-test counts and binary download URLs will be attached on the GitHub Release by the publisher.

## Delivered

- Native Android (Kotlin/Compose) and iOS (SwiftUI) clients sharing one dialect catalog and v2 model manifests.
- On-device pipeline using the Qwen3-ASR family, AngelSlim Hy-MT, and the Qwen3-TTS family.
- Voice reference files on device. Empty reference text stays embedding-only; nothing invents a transcript.
- One official ONNX Runtime 1.24.2 per mobile client (ASR and TTS). Native ASR/MT libraries built from pinned source (`scripts/build_android_native`, `scripts/build_ios_native`).
- Honest gates: draft manifests cannot become app-ready; missing files report remaining bytes; `scripts/verify --mode fast` runs without downloading weights.
- Host and Android emulator execution of real graphs. Integer TTS quantization and CP-only BF16 failed the declared voice-quality gates. The tested CoreML code-predictor configuration was slower than CPU. These candidates remain disabled.

TTS API2 (unified talker, ICL reference encoder, streaming vocoder) is compiled and documented for developers. Shared `tts.json` selects API contract 2 and remains `draft`; API1 compatibility is retained. The final package removes two unused support files (12.6 MB).

## What you can download / how to build

GitHub Release assets (URLs filled in at publish time):

- Source tarball / zip for this tag.
- Checksums and third-party notices.
- Optional host/emulator APK if the publisher attaches one. Model weights are **not** attached.

From a checkout:

```bash
scripts/doctor
scripts/verify --mode fast

# Android native, then Gradle
python3 scripts/build_android_native --ndk "$ANDROID_NDK_HOME"
cd android && ./gradlew :app:assembleDebug

# iOS (full Xcode required)
python3 scripts/build_ios_native
```

Weights:

```bash
export AURALIS_CACHE="${AURALIS_CACHE:-$HOME/Library/Caches/Auralis}"
python3 convert/fetch_model.py --package asr
python3 convert/fetch_model.py --package mt
python3 convert/fetch_model.py --package tts --local-source "$AURALIS_CACHE/tts/api2-release"
```

Fetch only copies paths listed in the manifest and checks hashes before keeping files. Put working copies under `$AURALIS_CACHE`; do not commit them.

## Known limits

- ASR, MT, and TTS manifests remain `draft`.
- No physical phone in this release. Emulator chain and host numbers are not p95, thermal, or battery results.
- Full iOS device build needs complete Xcode plus iPhoneOS/Simulator SDKs. Catalyst typecheck is recorded separately and is not an iOS link.
- Quality, accessibility, and long-run energy gates are open.
- API2 package/runtime reports are the latest engineering snapshot, not a finished Play/App Store binary and not a completed CI matrix.

## Design choices kept

- No stub graphs, fixture audio, or silent-success paths when a model or environment is missing.
- One ORT per mobile app, not a second Runtime next to sherpa.
- One talker session for prefill and decode when API2 is used; not two copies of the same weights.
- Streaming vocoder consumes codec frames and does not invent extra PCM at EOF.
- Quantization and CoreML candidates that failed identity/ASR gates, or that were slower on the measured CPU path, stay out of the default.
