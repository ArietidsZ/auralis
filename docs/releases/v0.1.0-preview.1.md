# Auralis v0.1.0-preview.1

**Developer Preview.** Prerelease tag `v0.1.0-preview.1`. Repository: [ArietidsZ/auralis](https://github.com/ArietidsZ/auralis).

Offline dialect speech translation on Android and iOS: ASR → MT → TTS, with optional voice cloning from a local reference. No network inference.

Developer Preview source and build tooling. Model packages stay `draft`; weights are not in the git tree. No store listing, hardware certification, or phone performance numbers. Test counts and the CI job URL will be filled in later.

## Delivered

- Native Android (Kotlin/Compose) and iOS (SwiftUI) clients sharing one dialect catalog and v2 model manifests.
- On-device pipeline using the Qwen3-ASR family, AngelSlim Hy-MT, and the Qwen3-TTS family.
- Voice reference files on device. Empty reference text stays embedding-only; nothing invents a transcript.
- One official ONNX Runtime 1.24.2 per mobile client (ASR and TTS). Native ASR/MT libraries built from pinned source (`scripts/build_android_native`, `scripts/build_ios_native`).
- Honest gates: draft manifests cannot become app-ready; missing files report remaining bytes; `scripts/verify --mode fast` runs without downloading weights.
- Host and Android emulator runs of real graphs. Integer TTS quantization and CP-only BF16 failed predeclared speaker-identity/ASR gates. A measured CoreML code-predictor setup was slower than CPU (not an identity-gate result). None of these are defaults.

TTS API2 (unified talker, ICL reference encoder, streaming vocoder) is compiled and documented for developers. Shared `tts.json` selects API contract 2 and remains `draft`; API1 compatibility is retained. The final package removes two unused support files (12.6 MB).

Model weights are **not** among these files.

From a checkout:

```bash
scripts/doctor
scripts/verify --mode fast
```

Android native, then Gradle (subshell so later commands stay at repo root):

```bash
python3 scripts/build_android_native --ndk "$ANDROID_NDK_HOME"
( cd android && ./gradlew :app:assembleDebug )
```

iOS (full local Xcode required):

```bash
python3 scripts/build_ios_native
```

Weights. `fetch_model.py` defaults to `<repo>/models`; pass `--dest` to use the cache:

```bash
export AURALIS_CACHE="${AURALIS_CACHE:-$HOME/Library/Caches/Auralis}"
python3 convert/fetch_model.py --package asr --dest "$AURALIS_CACHE/models"
python3 convert/fetch_model.py --package mt --dest "$AURALIS_CACHE/models"
python3 convert/fetch_model.py --package tts --dest "$AURALIS_CACHE/models" --local-source "$AURALIS_CACHE/tts/api2-release"
```

Fetch only copies paths listed in the manifest and checks hashes.

Device-test WAVs and voice references are not in git:

```bash
python3 scripts/prepare_android_test_assets --samples-dir /path/to/samples
```

Optional captured code-predictor tensors:

```bash
python3 scripts/prepare_android_test_assets --samples-dir /path/to/samples --cp-inputs-dir /path/to/bf16_cp_inputs
```

## Known limits

- ASR, MT, and TTS manifests remain `draft`.
- No physical phone in this release. Emulator chain and host numbers are not p95, thermal, or battery results.
- CI run `34114668822` produced three-slice native builds, an unsigned iOS device link, and a simulator app. Remaining failures: Swift tests missing import / SwiftPM core, and Android Aliyun 502 (being fixed). Not a green matrix.
- Local iOS still needs complete Xcode plus iPhoneOS/Simulator SDKs. Catalyst typecheck is not an iOS link.
- Quality, accessibility, and long-run energy gates are open.
- API2 reports are the latest engineering snapshot. Gradle/CI defaults remain open.
- GPU / Hy-MT2 2bit shipping in [the earlier roadmap](../viaim-parity-refactor-plan.md) is a later phase. This preview does not complete it.

## Design choices kept

- No stub graphs, fixture audio, or silent-success paths when a model or environment is missing.
- One ORT per mobile app, not a second Runtime next to sherpa.
- One talker session for prefill and decode when API2 is used; not two copies of the same weights.
- Streaming vocoder consumes codec frames and does not invent extra PCM at EOF.
- Quantization/BF16 that failed identity/ASR gates stay off. The slower CoreML CP configuration stays off for performance, not because it failed those gates.
